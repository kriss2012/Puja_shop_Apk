# 🛕 Online Puja Store App

An Android E-Commerce Application for purchasing **Puja Samagri, Havan Samagri, and Religious Items** online.

This app allows users to browse, select, and purchase spiritual products easily from their mobile device.

---

## 📱 App Overview

Online Puja Store is designed to provide:

- 🛒 Easy shopping experience
- 🔍 Product browsing by category
- 💳 Secure payment integration
- 📦 Order placement system
- 🔐 Firebase backend support
- 📱 Clean and simple UI

---

## 🛍️ Product Categories

- 🌸 Daily Puja Samagri  
- 🔥 Havan Samagri  
- 🪔 Diyas & Wicks  
- 📿 Mala & Spiritual Items  
- 🧂 Kumkum, Haldi & Powders  
- 📖 Religious Books  
- 🎁 Festival Special Kits

## 🛠️ Tech Stack

- **Language:** Kotlin / Java

## 📦 APK Installation

1. Download the APK file.
2. Enable **Install from Unknown Sources** in your Android settings.
3. Install the APK.
4. Open the app and start shopping.

## 🔐 Firebase Setup

1. Create project in Firebase Console.
2. Add Android App with package name.
3. Download `google-services.json`.
4. Place it inside `app/` folder.
5. Enable:
   - Authentication
   - Firestore Database
   - Storage

---
